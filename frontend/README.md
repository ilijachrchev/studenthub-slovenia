## StudentHub Slovenia
Centralized platform for discovering and managing student events across
Slovenian universities. Developed as a Systems III seminar project.

## Tech stack

- **Front end:** React (Vite), JavaScript
- **Back end:** Express (Node.js)
- **Database:** MySQL

## Project structure
studenthub/
frontend/   React front end (Vite)
backend/   Express back end
